# 수동 PDF 대조 감사 - 2026-07-31

## 목적

이 문서는 PDF 원문과 SQLMate 등록 문제를 직접 대조하는 수동검사의 시작 기록이다. 아직 전체 등록 문제를 모두 수동 검수했다는 의미가 아니다.

검사 방식은 다음과 같다.

1. PDF 페이지를 이미지로 렌더링한다.
2. 현재 SQLMate에 등록된 문제와 원문 PDF 페이지를 직접 비교한다.
3. 결과를 PASS, FIX APPLIED, FIX REQUIRED로 구분한다.
4. 확인된 오류만 수정한다.
5. 관리자용 출처 메타데이터는 일반 문제풀이 화면에 노출하지 않는다.

## 렌더링한 원문

- `SQL-자격검정-실전문제.pdf`: 96, 99, 102, 104, 105 페이지를 시각적으로 확인했다.
- `sqlp_subject3_full.pdf`: 8 페이지를 시각적으로 확인했다.
- `SQLP_실기_기출복기_예상문제집.pdf`: 1 페이지를 시각적으로 확인했다.

렌더링 산출물은 `tmp/manual-audit/` 아래의 로컬 임시 감사 자료로만 사용한다.

## 앞으로 적용할 규칙

- 문제 본문, 선택지, SQL, 표, 실행계획, 정답, 해설을 PDF 원문과 직접 대조하지 않은 문제는 `Original`로 취급하지 않는다.
- PDF의 SQL이나 상황을 유지하더라도 선택지나 질문 방향이 바뀌면 `Variant`로 분류한다.
- 전체 문제 캡처 이미지를 문제 대체물로 사용하지 않는다. 가독성이 필요한 표, ERD, 실행계획, Trace에 한해 구조화된 자료나 집중 이미지 자료를 사용한다.
- PDF 파일명, 페이지, 추출 상태, generation mode, review status는 일반 학습자 화면에 표시하지 않는다.
